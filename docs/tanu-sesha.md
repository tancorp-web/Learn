# ตนุเศษ (HORA rule F-009)

สถานะ: **ยืนยันตามหลักที่เจ้าของโครงการรับรอง**  
ขอบเขตการใช้งาน: **ดวงกำเนิดและดวงจร** โดยดวงกำเนิดใช้ลัคนากำเนิด/ดาวกำเนิด และดวงจรใช้ลัคนาจร/ดาวจรของช่วงเวลานั้น

## หลักคำนวณ

1. หาราศีลัคนากำเนิด แล้วหาเจ้าเรือนราศีนั้นเป็นดาวตนุลัคน์
2. นับราศีจากราศีลัคนากำเนิดเป็น 1 ไปถึงราศีที่ดาวตนุลัคน์สถิต เป็นจำนวน A
3. หาเจ้าเรือนของราศีที่ดาวตนุลัคน์สถิต แล้วนับจากราศีนั้นเป็น 1 ไปถึงราศีที่ดาวเจ้าเรือนดังกล่าวสถิต เป็นจำนวน B
4. คำนวณ A × B แล้วหารด้วย 7 ใช้เศษเทียบดาว 1 อาทิตย์, 2 จันทร์, 3 อังคาร, 4 พุธ, 5 พฤหัสบดี, 6 ศุกร์, 7 เสาร์ หากเศษเป็น 0 ให้ใช้เลข 7 (เสาร์)
5. **ข้อยกเว้นพิเศษที่ผู้ใช้ยืนยัน:** ถ้าดาวตนุลัคน์สถิตในราศีเดียวกับลัคนา ซึ่งเป็นราศีเกษตรของดาวตนุลัคน์ ให้ตนุเศษเป็นดาวตนุลัคน์ดวงนั้นทันที ไม่ใช้ผลจากสูตรคูณหาร 7

## ตารางผลลัพธ์เมื่อเข้าเงื่อนไขพิเศษ

| ราศีลัคนา | ตนุลัคน์และตนุเศษเมื่อดาวอยู่เกษตรตัวเอง |
|---|---|
| เมษ / พิจิก | อังคาร (๓) |
| พฤษภ / ตุลย์ | ศุกร์ (๖) |
| เมถุน / กันย์ | พุธ (๔) |
| กรกฎ | จันทร์ (๒) |
| สิงห์ | อาทิตย์ (๑) |
| ธนู / มีน | พฤหัสบดี (๕) |
| มังกร / กุมภ์ | เสาร์ (๗) |

ใช้กฎเดียวกันกับตนุเศษจร โดยเปลี่ยนจุดเริ่มต้นเป็นลัคนาจร และตรวจตำแหน่งดาวจรของช่วงเวลานั้น หากไม่เข้าเงื่อนไขพิเศษ ให้ใช้สูตรมาตรฐานตามข้อ 1–4

## การแสดงผล

- ในตารางดาวกำเนิด ให้ต่อท้ายชื่อดาวตนุเศษด้วยเครื่องหมาย + เช่น ศุกร์+
- ในวงล้อ ให้ต่อท้ายเลขดาวกำเนิดที่เป็นตนุเศษด้วย +
- ในส่วนวิเคราะห์ตนุเศษจร ให้ใช้กฎพิเศษเดียวกันกับลัคนาจรและดาวจรของช่วงเวลานั้น
- ห้ามใส่เครื่องหมาย + ให้ดาวจรในวงล้อ/ตารางดวงกำเนิด แม้ดาวจรชื่อเดียวกับดาวตนุเศษกำเนิด
- หากข้อมูลดาวกำเนิดไม่ครบพอคำนวณ ให้ไม่ทำเครื่องหมายและแสดงว่าไม่สามารถคำนวณได้
