# HORA — คลังความรู้ความหมายฤกษ์ 27

สถานะ: ฐานความรู้เฉพาะ 27mean; ยังไม่เชื่อม UI และยังไม่พร้อมใช้เป็นคำพยากรณ์ครบทุกฤกษ์
ปรับปรุง: 2026-11-15

## 1. แหล่งความหมายที่อนุญาต
ใช้เฉพาะบทความ “๒๗ กลุ่มดาวฤกษ์กับอาชีพและการดำเนินชีวิตของคุณ” โดย อ.ยอดธง ทับทิวไม้ ที่ https://27mean.blogspot.com/ เท่านั้น
ห้ามผสมคัมภีร์โบราณ ศาสตร์ Jyotish/Vedic จากแหล่งอื่น หรือความหมายดาว/ราศีจากสำนักอื่น

## 2. หน้าที่ของ HORA
HORA ใช้ตำแหน่งดาวจาก Suriyayatra engine ของ HORA เพื่อระบุฤกษ์ 27 และบาท 108 แล้วค้นความหมายจากบทความ 27mean เท่านั้น
- ไม่คำนวณตำแหน่งดาวซ้ำในชั้นความรู้
- ไม่ใช้ Lahiri, Tropical หรือ ephemeris ภายนอกแทน HORA
- lookup ใช้ช่วง [start,end) และไม่ปัดเศษก่อนแบ่งช่วง
- ฤกษ์ละ 800 ลิปดา; บาทละ 200 ลิปดา

## 3. ข้อมูลที่แสดงได้
ความหมายทางนามธรรม/จิตวิทยา บุคลิก จุดเด่น ข้อควรระวัง อาชีพและบุคคลที่เกี่ยวข้อง รวมถึงข้อมูลประกอบ เช่น ช่วงวันที่ สัญลักษณ์ สี ธาตุ คู่ฤกษ์และบุคคลตัวอย่าง เฉพาะเมื่อพบในบทความ
ความหมายเฉพาะบาทแสดงได้เมื่อบทความระบุบาทนั้นชัดเจนเท่านั้น ข้อมูลประกอบสมัยใหม่ต้องแยกจากความหมายทางนามธรรม ไม่ใช้เป็นกฎคำนวณ

## 4. ห้ามนำมาปะปน
- Bṛhat Jātaka, Bṛhat Parāśara, Bṛhat Saṃhitā หรือคัมภีร์อื่น
- ความหมายดาวแบบ Jyotish/Vedic จากแหล่งอื่น
- การสังเคราะห์ดาว × ฤกษ์ × ราศี × ภพ
- การอนุมานความหมายบาทจากองศาอย่างเดียว
- ข้อมูลผู้ใช้หรือแหล่งอื่นที่ยังไม่ยืนยันกับบทความ 27mean

## 5. สถานะข้อมูล
- partial: พบข้อความจากดัชนี/ข้อความบทความบางส่วน แต่ยังตรวจหน้าเต็มและภาพประกอบไม่ครบ
- missing: ยังไม่มีข้อความเพียงพอจากแหล่งหลัก
- verified: ตรวจต้นฉบับเต็มและยืนยันฟิลด์แล้ว
- conflict: ต้นฉบับมีข้อความขัดกัน
ห้ามแสดง partial/missing เป็นข้อมูลยืนยันสมบูรณ์ และห้ามเติมข้อความที่ไม่มีหลักฐาน

## 6. ความคืบหน้ารอบล่าสุด
- โครงสร้าง 27 ฤกษ์และ 108 บาทครบ ตรวจช่วงต่อเนื่อง ไม่มีช่องว่างหรือซ้อน
- ได้รับข้อความต้นฉบับจากผู้ใช้เพิ่มเติมสำหรับฤกษ์ 19–20 และ 23–25; เพิ่มบุคลิกสมัยใหม่ของมูละ (19) และบุรพาสาฬหะ (20), ความหมาย/อาชีพของศตภิษัช (24) และข้อมูลประกอบของธนิษฐา (23)
- สถานะรวม: 25 รายการ partial, 2 รายการ missing, 0 รายการ verified
- ฤกษ์ 21–22 ยังขาดข้อความความหมายที่อ่านได้จากแหล่งหลัก; ฤกษ์ 20 มีเฉพาะบุคลิกสมัยใหม่ที่ผู้ใช้ส่งมา ยังไม่มีความหมายนามธรรมและอาชีพ; ฤกษ์ 19 มีเฉพาะบุคลิกสมัยใหม่ที่ผู้ใช้ส่งมา ยังไม่มีความหมายนามธรรมและอาชีพ; ฤกษ์ 23 มีเฉพาะข้อมูลประกอบที่ผู้ใช้ส่งมา ยังไม่มีความหมายทั่วไป
- รายละเอียดรายบาทยังไม่ครบ 108 บาท; การมีช่วงองศาของบาทไม่ได้แปลว่ามีความหมายเฉพาะบาท
- ข้อมูลจาก snippet/index ยังต้องตรวจทานกับหน้าเต็มและภาพประกอบ จึงยังไม่ถือเป็น verified
