# HORA — คลังความรู้ความหมายฤกษ์ 27

สถานะ: ฐานความรู้เฉพาะ 27mean; ยังไม่เชื่อม UI และยังไม่พร้อมใช้เป็นคำพยากรณ์ครบทุกฤกษ์
ปรับปรุง: 2026-11-15

## 1. หลักการเดียวของโครงการ

ความหมายฤกษ์ 27 ใน HORA ใช้แหล่งเดียวคือ 27mean:
“๒๗ กลุ่มดาวฤกษ์กับอาชีพและการดำเนินชีวิตของคุณ” โดย อ.ยอดธง ทับทิวไม้
https://27mean.blogspot.com/

ไม่ผสมคัมภีร์โบราณ ไม่ผสม Jyotish/Vedic จากสำนักอื่น ไม่สร้างกรอบสังเคราะห์ดาวทั้ง 9 และไม่ใช้ความหมายดาวหรือราศีมาทดแทนความหมายฤกษ์

## 2. HORA ทำหน้าที่อะไร

HORA ใช้ตำแหน่งดาวที่คำนวณจาก Suriyayatra engine ของ HORA เท่านั้น เพื่อค้นว่า longitude ตกในฤกษ์ใดและบาทใด จากนั้นดึงความหมายที่มีหลักฐานจาก 27mean มาแสดง
- ห้ามคำนวณตำแหน่งดาวซ้ำในชั้นความรู้
- ห้ามใช้ Lahiri, Tropical หรือค่า ephemeris จากเว็บอื่นแทน HORA
- lookup ใช้ช่วง [start,end) ไม่ปัดเศษก่อนแบ่งช่วง
- 27 ฤกษ์มีช่วงละ 800 ลิปดา; 108 บาทมีช่วงละ 200 ลิปดา

## 3. สิ่งที่แสดงได้จาก 27mean

แสดงเฉพาะข้อมูลที่พบและตรวจสอบย้อนกลับได้ในต้นฉบับ เช่น
- ความหมายโดยรวมของฤกษ์
- ความหมายแยกตามบาท เมื่อบทความแยกไว้จริง
- บุคลิก จุดเด่น และข้อควรระวัง
- อาชีพและการดำเนินชีวิต
- สี ธาตุ สัญลักษณ์ คู่ฤกษ์ ช่วงวันที่ หรือบุคคลตัวอย่าง เฉพาะเมื่อยืนยันได้ว่าเป็นข้อมูลในบทความ

ข้อมูลประกอบไม่ใช่สูตรคำนวณ และห้ามนำไปใช้เป็นเงื่อนไขคำนวณตำแหน่งดาว

## 4. สิ่งที่ห้ามนำมาปะปน

- Bṛhat Jātaka และคำบรรยายจันทร์กำเนิด
- Bṛhat Parāśara Horā Śāstra หรือความหมายพื้นฐานดาวจากคัมภีร์
- Bṛhat Saṃhitā และรายชื่อเทพประจำฤกษ์
- ความหมายดาวแบบ Jyotish/Vedic จากแหล่งอื่น
- การสังเคราะห์ดาว × ฤกษ์ × ราศี × ภพ
- การอนุมานความหมายบาทจากองศาอย่างเดียว
- ข้อมูลที่ผู้ใช้ส่งซึ่งยังไม่ยืนยันกับ 27mean ให้เก็บสถานะรอตรวจ ไม่แสดงเป็นข้อเท็จจริงจากแหล่ง

## 5. กฎความครบถ้วน

- verified: ตรวจต้นฉบับได้ตรงข้อความ/ฟิลด์
- partial: มีข้อมูลเพียงบางส่วน
- pending: รอตรวจต้นฉบับ
- missing: ยังไม่มีข้อมูลที่ใช้ได้
- conflict: ข้อความต้นฉบับขัดกัน

ห้ามเติมข้อความที่หายไป ห้ามแต่งความหมายให้ครบ 27/108 และห้ามแสดง partial/missing/pending เป็นคำพยากรณ์ยืนยันแล้ว

## 6. สถานะการตรวจรอบนี้

ข้อมูล JSON มี 27 รายการครบในเชิงโครงสร้าง แต่ความหมายยังไม่ครบ:
- 18 รายการมีข้อความบางส่วนจาก 27mean (partial)
- 9 รายการยังไม่มีข้อความที่ใช้ได้เพียงพอ (missing)
- มีข้อความแยกบาทในบางฤกษ์เท่านั้น; ไม่ได้มีความหมายครบ 108 บาท
- รายละเอียดบาททั้ง 108 เป็นช่วงองศาสำหรับ lookup ไม่ใช่คำพยากรณ์โดยตัวมันเอง
- ข้อมูลฤกษ์ 25–27 ที่เคยใส่จากข้อความผู้ใช้ถูกพักไว้เป็น missing จนกว่าจะตรวจยืนยันกับ 27mean
- การค้นดัชนีเว็บรอบล่าสุดพบข้อความเพิ่มของฤกษ์ 4 และ 10–18 รวมถึงการแบ่งบาทบางกลุ่ม แต่หน้า Blogspot ยังไม่แสดงเนื้อหาเต็มเป็นบรรทัด จึงยังต้องตรวจทานต้นฉบับและภาพประกอบ
- ฤกษ์ 19–23 และ 25–27 ยังไม่มีข้อความความหมายที่ยืนยันได้จากการค้นรอบนี้; ฤกษ์ 24 พบเพียงหัวข้อ/ข้อมูลไม่พอสำหรับถอดความ

## 7. ไฟล์ข้อมูล

- data/nakshatra-27-reference.json — ชื่อและช่วงองศาฤกษ์ 27 สำหรับ lookup เท่านั้น
- data/nakshatra-108-padas.json — ช่วงองศาบาท 108 สำหรับ lookup เท่านั้น พร้อมสถานะว่าพบข้อความรายบาทหรือยัง
- data/nakshatra-interpretations.json — ความหมายและสถานะข้อมูลจาก 27mean เท่านั้น
- data/nakshatra-sources.json — แหล่งเดียวสำหรับความหมายและแหล่งโครงสร้างทางเทคนิค

## 8. เงื่อนไขก่อนเชื่อมหน้าคำนวณ

1. ตรวจต้นฉบับ 27mean ให้ครบทุกกลุ่มและภาพประกอบ
2. ยืนยันว่าข้อความใดเป็นความหมายทั้งฤกษ์ และข้อความใดจำเพาะบาท/ราศี
3. บันทึกแหล่งอ้างอิงรายฟิลด์และสถานะความครบถ้วน
4. ตรวจ JSON และ QA ช่วง 27/108
5. ขออนุมัติแยกก่อนเชื่อม UI หรือเปลี่ยนไฟล์หน้าคำนวณ
