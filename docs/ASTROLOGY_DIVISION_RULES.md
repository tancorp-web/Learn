# หลักอ้างอิงตรียางค์และนวางค์ของ HORA

สถานะ: **บันทึกองค์ความรู้สำหรับใช้งานครั้งถัดไป**  
ขอบเขต: เป็นเอกสารอ้างอิง ไม่ใช่การอนุมัติให้เปลี่ยนสูตรคำนวณดาวใน `main.js`

## 1. ต้องแยกดาวเดิมและดาวจร

ให้พิจารณาแยกกัน 4 กรณี ห้ามใช้แทนกันโดยไม่ตั้งใจ

1. **ดาวเดิมครองตรียางค์** — พิจารณาตรียางค์จากตำแหน่งดาวในดวงกำเนิด
2. **ดาวจรครองตรียางค์** — พิจารณาตรียางค์จากตำแหน่งดาวจร ณ วันและเวลาที่ตรวจสอบ
3. **ดาวเดิมครองนวางค์** — พิจารณานวางค์จากตำแหน่งดาวในดวงกำเนิด
4. **ดาวจรครองนวางค์** — พิจารณานวางค์จากตำแหน่งดาวจร ณ วันและเวลาที่ตรวจสอบ

## 2. ตรียางค์ตามธาตุ — ข้อมูลอ้างอิงที่ตกลงไว้

แบ่งแต่ละราศีเป็น 3 ส่วน ส่วนละ 10 องศา เรียงเป็น ปฐม / ทุติย / ตติย ตามลำดับ

| ธาตุ | ปฐมตรียางค์ (0°–10°) | ทุติยตรียางค์ (10°–20°) | ตติยตรียางค์ (20°–30°) |
|---|---:|---:|---:|
| ไฟ | 3 อังคาร | 1 อาทิตย์ | 5 พฤหัสบดี |
| ดิน | 6 ศุกร์ | 4 พุธ | 7 เสาร์ |
| ลม | 4 พุธ | 6 ศุกร์ | 8 ราหู* |
| น้ำ | 2 จันทร์ | 3 อังคาร | 5 พฤหัสบดี |

ธาตุของราศี:
- ไฟ: เมษ, สิงห์, ธนู
- ดิน: พฤษภ, กันย์, มกร
- ลม: มิถุน, ตุล, กุมภ์
- น้ำ: กรกฎ, พิจิก, มีน

* สำหรับตติยตรียางค์ธาตุลม มีตัวเลือกที่ผู้ใช้ระบุไว้ทั้ง **8 ราหู** และ **7 เสาร์**; การแสดงผลล่าสุดเลือก 8 ราหูตามตัวเลือกแรก แต่ควรยืนยันตามตำราที่โครงการจะใช้เป็นมาตรฐานก่อนตรึงเป็นกฎถาวร

## 3. แนวทางนำไปใช้ในระบบ

- คำนวณตำแหน่งดาวเดิมและดาวจรจากแหล่งข้อมูล/สูตรของแต่ละระบบตามเดิม แล้วระบุว่าเป็นดวงเดิมหรือดาวจรให้ชัดเจนก่อนแปลงเป็นตรียางค์หรือนวางค์
- แสดงชื่อประเภท (ตรียางค์/นวางค์), ชนิดตำแหน่ง (ดาวเดิม/ดาวจร), ราศี และส่วนย่อยที่ได้อย่างชัดเจน
- อย่านำกฎตรียางค์ไปใช้แทนกฎนวางค์ ทั้งสองเป็นการแบ่งส่วนคนละแบบ
- อย่าเปลี่ยนสูตรคำนวณดาวอื่นหรือสูตรหลักใน `main.js` จากเอกสารนี้เพียงอย่างเดียว
- ก่อนนำไปเป็นสูตรคำนวณอัตโนมัติ ให้จัดทำกรณีทดสอบอ้างอิงและตรวจเทียบกับหลักตำราที่ผู้ใช้ยืนยัน

## 4. ข้อกำหนดที่ยังต้องยืนยัน

เอกสารนี้บันทึกขอบเขตและหลักการแยกประเภทไว้แล้ว แต่ยังไม่ได้ระบุสูตรเต็มสำหรับการหานวางค์หรือการวินิจฉัยผลตามตำราเฉพาะสำนัก จึงห้ามแต่งเติมสูตรที่ยังไม่ได้รับการยืนยัน

## 5. พิษตรียางค์: พิษนาค / พิษครุฑ / พิษสุนัข

สถานะ: **DISCOVERY / ต้องยืนยันเกณฑ์ตำราก่อนเปิดใช้เป็นกฎอัตโนมัติ**

ขอบเขตความรู้ที่ต้องเก็บใน HORA:
- บันทึกประเภทพิษแยกจากการคำนวณตำแหน่งดาว โดยใช้ลองจิจูดจริงของดาวหรือลัคนาที่เครื่องคำนวณส่งมา
- แบ่งองศาภายในราศีเป็น 3 ตรียางค์: ปฐม (0° ≤ d < 10°), ทุติย (10° ≤ d < 20°), ตติย (20° ≤ d < 30°) โดย (d) คือองศาภายในราศีในช่วง 0°–30° ไม่ใช่ลองจิจูดวงกลม 0°–360°
- ต้องแยกผลของดาวเดิม ดาวจร และลัคนาให้ชัด พร้อมเก็บราศี องศา/ลิปดา ตรียางค์ และชื่อประเภทพิษที่จับคู่ได้
- ค่าพิษเป็นข้อมูลความรู้/คุณสมบัติที่อนุมานจากตำราที่เลือก ไม่ใช่ค่าที่ใช้แก้ตำแหน่งดาว ราศี ภพ หรือลัคนา
- ห้าม hard-code ผลลัพธ์ตามชื่อดาวหรือบุคคล และห้ามยกตัวอย่างดวงใดดวงหนึ่งให้กลายเป็นสูตรทั่วไป
- หากกฎยังไม่ยืนยัน ให้ส่งสถานะ `DISCOVERY` หรือ `PROVISIONAL` และไม่ใช้ตัดสินคำทำนายอัตโนมัติ

### ตัวอย่างอ้างอิงที่ต้องเก็บไว้ตรวจสอบ

ในบันทึกโครงการก่อนหน้า มีตัวอย่างการจัดประเภทในกรณีอ้างอิงว่า เกตุ/พุธ = พิษนาค, ศุกร์ = พิษครุฑ และลัคนา = พิษสุนัข ข้อมูลนี้เป็น **ตัวอย่างผลที่ต้องตรวจย้อนกับตำแหน่งองศาและเกณฑ์ตำรา** ไม่ใช่กฎว่าดาวเหล่านี้ต้องได้พิษชนิดนั้นทุกดวงหรือทุกตำแหน่ง

### ตารางจับคู่เบื้องต้นที่ผู้ใช้อนุมัติให้แสดงผลใน UI

สถานะ: **PROVISIONAL — แสดงสัญลักษณ์เพื่อทดลองใช้งานเท่านั้น; ยังไม่ถือเป็นเกณฑ์ตำราที่ตรวจยืนยันแล้ว**

| ประเภท | ตรียางค์ | ราศี |
|---|---|---|
| พิษนาค | ปฐม (0°–10°) | เมษ, กันย์, ธนู, มีน |
| พิษครุฑ | ทุติย (10°–20°) | พฤษภ, สิงห์, ตุล, กุมภ์ |
| พิษสุนัข | ตติย (20°–30°) | มิถุน, กรกฎ, พิจิก, มกร |

การใช้งานใน index5.html:
- แสดงรูปนก/ครุฑ รูปงู/นาค และรูปสุนัขขนาดเล็กสีแดงเข้ม ณ รัศมีแยกจากเลขดาวครองตรียางค์
- เปลี่ยนสีเลขดาวครองตรียางค์เป็นสีแดงเฉพาะ 12 ตำแหน่งที่เข้าตารางข้างต้น
- ไม่แสดงคำว่า “พิษ” บนวงล้อ และไม่เปลี่ยนลองจิจูดหรือสูตรคำนวณดาว
- ตารางนี้ใช้เฉพาะการแสดงผลชั่วคราว ไม่ใช้เป็นคำทำนายอัตโนมัติหรือเป็นหลักฐานยืนยันตำรา
- หากได้แหล่งอ้างอิง/ตารางจากตำราที่เลือกใช้ ต้องตรวจครบ 36 ช่องและปรับทั้งโค้ดกับเอกสารให้ตรงกัน

### ข้อกำหนดก่อนพัฒนาเป็นกฎในระบบ

1. ระบุชื่อ/หลักเกณฑ์ตำราที่ใช้เป็นมาตรฐานของโครงการ
2. ทำตารางจับคู่ครบทั้ง 12 ราศี × 3 ตรียางค์ และระบุพิษของแต่ละช่วงอย่างชัดเจน
3. กำหนดขอบเขตองศาแบบครึ่งเปิดเพื่อไม่ให้ค่าที่ 10°00′ หรือ 20°00′ ถูกจัดซ้ำ
4. สร้าง Golden Cases โดยระบุลองจิจูดจริงและผลที่คาดหวังสำหรับดาว ลัคนา ดาวเดิม และดาวจร
5. แยกไฟล์กฎความรู้ออกจาก engine คำนวณดาว และรัน regression tests ก่อนเชื่อมกับ UI

ห้ามเปลี่ยนสูตรคำนวณดาวหรือลัคนาที่ล็อกไว้จากการเพิ่มความรู้นี้เพียงอย่างเดียว
