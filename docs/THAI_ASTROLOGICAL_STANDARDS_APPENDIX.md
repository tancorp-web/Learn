# ภาคผนวกคำพยากรณ์มาตรฐานดาวและเกณฑ์องศา — HORA

เอกสารนี้จัดระเบียบข้อมูลเพิ่มเติมที่ผู้ใช้ส่งเมื่อ 2026-10-10 เพื่อเก็บรายละเอียดคำพยากรณ์แยกตามดาวและเกณฑ์ความสัมพันธ์ดาวไว้ตรวจสอบต่อ เป็นข้อมูลเชิงตำรา/ความเชื่อ ไม่ใช่ข้อเท็จจริงทางวิทยาศาสตร์ และยังไม่ใช่กฎคำนวณที่ได้รับการยืนยันทุกข้อ

## 1. ข้อควรแก้เรื่องชื่อภาษาอังกฤษ

คำแปลอังกฤษที่แนบมากับข้อความต้นทางบางรายการไม่ตรงกับศัพท์โหราศาสตร์ที่ใช้กันทั่วไป จึงไม่ควรนำไปเป็นชื่อทางเทคนิคในโปรแกรมโดยตรง:

- **เกษตร** หมายถึงตำแหน่งเรือนของดาว (domicile/rulership) ไม่ใช่คำเดียวกับ exaltation
- **อุจจ์** ใช้เทียบกับ exaltation
- **นิจ** ใช้เทียบกับ debilitation/fall
- **ประ/ประเกษตร** ตามคำอธิบายต้นฉบับในเอกสารนี้เป็นศัพท์เฉพาะอีกชุดหนึ่ง ซึ่งมักอธิบายว่าอยู่ตรงข้ามเรือนเกษตรในแนวทางที่ผู้ใช้ส่งมา แต่ห้ามเหมารวมกับคำว่า debilitation โดยไม่ระบุสำนัก
- **อุจจาวิลาส, อุจจาภิมุข, มหาจักร, จุลจักร, ราชาโชค, เทวีโชค** ควรใช้ชื่อไทยเป็นหลักจนกว่าจะยืนยันศัพท์อังกฤษที่สอดคล้องกับตำราเฉพาะ

## 2. ความหมายสรุปของมาตรฐานสิบประเภท

| ชื่อ | ความหมายตามบันทึกต้นทาง | ข้อควรระวัง |
|---|---|---|
| เกษตร | ความมั่นคง หลักฐาน ความรู้ วิชาการ และความก้าวหน้า | แยกจากอุจจ์ |
| ประเกษตร/ประ | ความผันแปร อุปสรรค ความล่าช้า และผลไม่สมหวัง | ต้องยืนยันตารางราศีตามสำนัก |
| อุจจ์ | พลังเด่น ความแข็งแกร่ง ความรุ่งโรจน์ และผลที่ชัดเจน | อาจพิจารณาระดับราศีและองศาแยกกัน |
| นิจ | เสื่อมกำลัง ติดขัด อับเฉา หรือความตกต่ำตามคำพยากรณ์ | ข้อความองศาที่ให้มาขัดแย้งกันหลายจุด |
| อุจจาวิลาส | การไต่ขึ้นสู่ตำแหน่งอุจ/มหาอุจ ตามคำอธิบายต้นทาง | ต้องยืนยันตำแหน่งและองศา |
| อุจจาภิมุข | ตำแหน่งถัดจากอุจไปข้างหน้าตามคำอธิบายต้นทาง ให้คุณลดลง | ต้องยืนยันราศีเริ่มนับและทิศทาง |
| มหาจักร | อิทธิพลโดดเด่น โลดโผน พลิกแพลง ฝ่าอุปสรรค | ต้องมีตารางเฉพาะ |
| จุลจักร | ต้นฉบับระบุว่าอยู่ตรงข้ามมหาจักรและให้คุณน้อยกว่า | ห้ามสร้างค่าด้วยการกลับตารางเอง |
| ราชาโชค | วาสนา ความนิยม การอุปถัมภ์ และโอกาส | ต้องมีตารางเฉพาะ |
| เทวีโชค | ต้นฉบับระบุว่าตรงข้ามราชาโชคและให้คุณน้อยกว่า เว้นแต่มีเงื่อนไขหนุน | ต้องยืนยันตารางก่อนคำนวณ |

## 3. เกษตรรายดาว — รายละเอียดตามต้นฉบับ

- **๑ อาทิตย์:** เกียรติยศ ตำแหน่งหน้าที่ อำนาจ บารมี ชื่อเสียง ความเป็นอิสระและความเชื่อมั่นในตนเอง; ด้านเงาที่ต้นฉบับกล่าวถึงคือความดื้อ ถือตัว และใจร้อน
- **๒ จันทร์:** ความนุ่มนวล สุภาพ เสน่ห์ ความเป็นที่รัก ความสะอาดเรียบร้อย ทรัพย์ และเรื่องมารดา; มีข้อสังเกตตามต้นฉบับเรื่องการเอาใจผู้อื่นและความเจ้าชู้
- **๓ อังคาร:** ความกล้า ขยัน สุขภาพ/พละกำลัง การตัดสินใจเร็ว งานทหาร ตำรวจ เกษตรกรรมและการค้า; ด้านเงาคือใจร้อน โมโหง่าย และขาดความนิ่มนวล
- **๔ พุธ:** ไหวพริบ การพูด การเขียน การประชาสัมพันธ์ ธุรกิจ การเจรจา การแก้ปัญหา การเรียนรู้เร็ว และการบริหาร
- **๕ พฤหัสบดี:** การศึกษา ทฤษฎี ศาสนา คุณธรรม สติปัญญา ความยุติธรรม ผู้ใหญ่ ครูอาจารย์ และโชคลาภ; ด้านเงาคือการเน้นทฤษฎีหรือใช้เวลาตัดสินใจ
- **๖ ศุกร์:** ศิลปะ ความงาม เสน่ห์ ความรัก รสนิยม การเงิน ธนาคาร เศรษฐศาสตร์ และงานสร้างสรรค์
- **๗ เสาร์:** ความอดทน ความเด็ดขาด การต่อสู้ระยะยาว เกษตรกรรม ที่ดิน เหมืองแร่ เครื่องกลและการบริหาร; ด้านเงาคือความกังวลและการเก็บความโกรธ
- **๘ ราหู:** ไหวพริบ การอ่านคน การปรับตัว เล่ห์เหลี่ยม ลาภผล และการทำงานในสถานการณ์ซับซ้อน; ด้านเงาคืออารมณ์และความตระหนี่ตามคำพยากรณ์เดิม
- **๙ เกตุ:** ต้นฉบับเปรียบคล้ายอาทิตย์แต่รุนแรงกว่า เน้นความดื้อ การเอาชนะ และการวางตัวโดดเด่น
- **๐ มฤตยู:** ความคิดประดิษฐ์ ค้นคว้า วิทยาศาสตร์ โหราศาสตร์ ความคิดริเริ่ม และการทำงานกับกลุ่ม/สมาคม
- **เนปจูน:** จินตนาการ สิ่งลึกลับ การค้นคว้าสิ่งไม่คุ้นเคยและการวางแผนระยะยาว; ต้นฉบับเตือนเรื่องความเพ้อฝันหรือการถูกหลอก
- **พลูโต:** การเปลี่ยนแปลง ฟื้นฟู ซ่อมแซม พัฒนาสิ่งเดิมให้ดีขึ้น ความมุ่งมั่นและการสร้างประโยชน์ส่วนรวม

**หลักพยากรณ์ที่บันทึกไว้:** ต้นฉบับระบุว่า “ดาวเกษตรต่อเกษตรเล็งกัน” อาจสัมพันธ์กับทรัพย์สมบัติวิบัติภายหลัง ให้เก็บเป็นคำพยากรณ์เฉพาะสำนัก ไม่ใช้เป็นกฎอัตโนมัติก่อนยืนยันบริบทและความหมายของคำว่าเล็งในตำรานั้น

## 4. ประเกษตรรายดาว — รายละเอียดตามต้นฉบับ

- **อาทิตย์:** ทรัพย์ มิตรสหาย ที่อยู่อาศัย ลาภผล และการทำดีได้ดีอาจติดขัด
- **จันทร์:** ความสัมพันธ์และหลักฐานความมั่นคงอาจไม่เป็นไปตามหวัง
- **อังคาร:** การพึ่งพาญาติและมิตรสหายอาจมีอุปสรรค
- **พุธ:** ความสัมพันธ์กับญาติ มิตร คู่ครอง หรือบุตรอาจไม่ราบรื่นตามคำพยากรณ์เดิม
- **พฤหัสบดี:** การพึ่งครู ผู้ใหญ่ หรือที่ปรึกษาอาจไม่เป็นไปตามหวัง
- **ศุกร์:** ต้นฉบับกล่าวถึงรูปร่าง/อวัยวะและสุขภาพ แต่ห้ามใช้แทนการประเมินสุขภาพจริง
- **เสาร์:** มิตรสหายอาจนำภาระหรือความเดือดร้อนมาให้
- **ราหู:** ต้นฉบับกล่าวถึงความขัดแย้ง ความไม่ซื่อตรง และภาพลักษณ์ที่ไม่สง่า

## 5. อุจจ์รายดาว — รายละเอียดตามต้นฉบับ

- **อาทิตย์:** ทรัพย์ ชัยชนะ ความเข้มแข็ง เกียรติ ความรู้และคุณธรรม
- **จันทร์:** ทรัพย์ เสน่ห์ ความเป็นที่รัก ความขยันและความอุดมสมบูรณ์
- **อังคาร:** ความกล้า คำพูดคม เกียรติ ชัยชนะและความเด็ดขาด โดยมีคำเตือนเรื่องโทสะ
- **พุธ:** ความรู้ ความร่าเริง การเป็นที่นิยมและความคล่องแคล่ว
- **พฤหัสบดี:** ปัญญา คุณธรรม ผู้ใหญ่สนับสนุน การให้อภัยและโชคลาภ
- **ศุกร์:** ทรัพย์ ความสุภาพ วาจาไพเราะ เมตตาและศิลปะ
- **เสาร์:** ความอดทน อำนาจ อายุยืน การสนับสนุนและความมั่นคง
- **ราหู:** ต้นฉบับให้ความหมายคล้ายเสาร์ในด้านทรัพย์และความเจริญ

## 6. อุจจาวิลาสรายดาว

คำอธิบายต้นทางกล่าวว่าเป็นตำแหน่งที่ดาวกำลังจะขึ้นสู่อุจ/มหาอุจ โดยให้ผลด้านการขยับขยายและยกระดับฐานะ:

- **อาทิตย์:** อาชีพ ตำแหน่ง ความรู้ และความสำเร็จ
- **จันทร์:** เสน่ห์ เมตตา การเป็นที่พึ่งและงานสาธารณะ
- **อังคาร:** ความกล้า การบังคับบัญชา งานทหาร/ตำรวจ งานช่างหรือเกษตร
- **พุธ:** ชื่อเสียง ความสามารถ ทรัพย์และความสัมพันธ์
- **พฤหัสบดี:** ความรู้ ความเชี่ยวชาญและการสอน
- **ศุกร์:** หลักธรรม การค้า ยศศักดิ์และทรัพย์
- **เสาร์:** ความขยัน อดออมและความมั่งคั่ง
- **ราหู:** เกียรติยศ ความรู้และงานที่ต้องอาศัยความกล้า

## 7. อุจจาภิมุขรายดาว

คำอธิบายต้นทางกล่าวว่าเป็นตำแหน่งที่เลยราศีอุจไปข้างหน้า ให้คุณลดลงและอาจมีลักษณะ “ทุกขลาภ”:

- **อาทิตย์:** ความรู้ ทรัพย์และเพื่อนฝูง
- **จันทร์:** ทรัพย์ ญาติบริวารและความนิยม
- **อังคาร:** เกียรติ อำนาจและความรวดเร็ว
- **พุธ:** ทรัพย์ บริวาร บุตรหลานและมนุษยสัมพันธ์
- **พฤหัสบดี:** ผู้ใหญ่สนับสนุน ความรู้และปัญญา
- **ศุกร์:** ความรู้คดีโลก/คดีธรรม ทรัพย์และบุคลิก
- **เสาร์:** ทรัพย์ อำนาจและความนับถือ
- **ราหู:** ชัยชนะ อำนาจ การปกครองและทรัพย์

ต้นฉบับยังกล่าวถึงภพ ๑, ๔, ๕, ๗, ๙, ๑๐, ๑๑ รวมทั้งภพกดุมภะ/ลาภะ และเงื่อนไขการเล็งกับดาวเกษตร ต้องแยกเป็นกฎย่อยและยืนยันก่อนใช้ในโปรแกรม

## 8. มหาจักรรายดาวและจุลจักร

ความหมายมหาจักรตามต้นฉบับ:
- **อาทิตย์:** ลาภยศ หลักฐาน อำนาจและความมั่งคั่ง
- **จันทร์:** รูปสมบัติ ทรัพย์ เกียรติ ที่ดินและฐานะ
- **อังคาร:** ความกล้า อำนาจ ความเด็ดเดี่ยวและความมั่งมี
- **พุธ:** ทรัพย์ บริวาร เกียรติด้านวิชาการและความเชี่ยวชาญ
- **พฤหัสบดี:** ความรู้ เกียรติและความสำเร็จใหญ่
- **ศุกร์:** ทรัพย์ คุณธรรมและชื่อเสียง
- **เสาร์:** ความมั่นคง การออมและอสังหาริมทรัพย์
- **ราหู:** อำนาจ การปกครอง บริวารและชัยชนะ

ต้นฉบับกล่าวว่าผลมหาจักรอาจเด่นเมื่อกุมลัคนา และให้ข้อสังเกตเฉพาะจันทร์ พุธ และราหู ต้องคงเป็นหมายเหตุรอยืนยัน ไม่ใช่กฎตัดสินอัตโนมัติ

จุลจักรตามต้นฉบับเป็นตำแหน่งตรงข้ามมหาจักร ให้คุณน้อยกว่า และอาจต้องกุมลัคนาพร้อมมีดาวเกษตรเรือนนั้นสนับสนุนจึงจะเด่น ต้องยืนยันตารางจริงก่อนคำนวณ

## 9. ราชาโชครายดาวและเทวีโชค

ราชาโชคตามต้นฉบับเน้นวาสนา ความนิยมและการอุปถัมภ์:
- **อาทิตย์:** ความนิยมและความก้าวหน้าทางราชการ
- **จันทร์:** ผู้ใหญ่สนับสนุนและคู่ครองมีวาสนา
- **อังคาร:** ผู้มียศหรือมิตรสหายช่วยเหลือ
- **พุธ:** ความนิยมด้านงานเขียน ธรรมะ สติปัญญาและวาทศิลป์
- **พฤหัสบดี:** นักปราชญ์ ครู อาจารย์หรือผู้ทรงศีลเมตตา
- **ศุกร์:** ความนิยมจากผู้คนและความก้าวหน้าในงาน
- **เสาร์:** ความนิยมด้านการงานและตำแหน่ง
- **ราหู:** บริวารและเครือข่ายจำนวนมาก รวมถึงโอกาสด้านทรัพย์ตามคำพยากรณ์

ต้นฉบับให้ความสำคัญเมื่อราชาโชคอยู่ในเรือนกัมมะแก่ลัคนา ส่วนเทวีโชคอธิบายว่าอยู่ตรงข้ามราชาโชคและให้คุณน้อยกว่า แต่หากกุมลัคนาอาจเด่นเป็นพิเศษ ทั้งหมดต้องยืนยันตารางหลักก่อนทำเป็นกฎ

## 10. คู่พระเคราะห์

| ประเภท | ความหมายตามต้นฉบับ |
|---|---|
| คู่ธาตุ | เกื้อหนุนสูง ส่งเสริมความมั่งคั่ง ความสุข ความสมบูรณ์และความยั่งยืน |
| คู่สมพล | เสริมกำลัง อำนาจ ความสามารถ ตำแหน่ง และการปกป้อง |
| คู่มิตร | มิตรภาพ ความเมตตา ความไว้วางใจและการช่วยเหลือในยามคับขัน |
| คู่ศัตรู | ความขัดแย้ง การทะเลาะ คดีความ อุปสรรคและความไม่ลงรอย |

คู่ดาวเหล่านี้เป็นข้อมูลความสัมพันธ์ระหว่างดาว ไม่ใช่สถานะตำแหน่งแบบเกษตร/อุจจ์ ต้องเก็บเป็นตารางหรือโมดูลแยกกัน และยังต้องมีตารางจับคู่ดาวจริงที่ผู้ใช้ยืนยัน

## 11. พุธและมฤตยู

- **มฤตยู:** ต้นฉบับกล่าวว่าความสัมพันธ์กับลัคนา เช่น กุม เล็ง โยค หรือตรีโกณ สื่อถึงความสนใจของเก่า การเก็บความลับและสิ่งลึกลับ
- **พุธ:** ใช้ตีความการพูด การเจรจา ธุรกิจ การประสานงาน นายหน้า การสอน การเทศน์ การเขียน การประพันธ์และการแก้ปัญหา
- เป็นแนวตีความ ไม่ใช่กฎคำนวณมาตรฐานดาว

## 12. ข้อมูลองศานิจที่ผู้ใช้ส่งมา — คงไว้เพื่อรอตรวจสอบ

ข้อความต้นทางระบุค่าต่อไปนี้ แต่ในหลายแถว “องศาจำกัด” และ “องศาที่จะไม่เป็นนิจเมื่อเกิน” ไม่สอดคล้องกัน จึงต้องเก็บเป็นบันทึกดิบเท่านั้น:

| ดาว | องศาจำกัดที่ระบุ | องศาที่ข้อความระบุว่าจะไม่เป็นนิจเมื่อเกิน | สถานะ |
|---|---:|---:|---|
| อาทิตย์ | 19° | 10° | ขัดแย้ง/รอยืนยัน |
| จันทร์ | 3° | 19° | ขัดแย้ง/รอยืนยัน |
| อังคาร | 28° | 12° | ขัดแย้ง/รอยืนยัน |
| พุธ | 15° | 15° ขึ้นไป | ต้องตรวจนิยามขอบเขต |
| พฤหัสบดี | 15° | 15° ขึ้นไป | ต้องตรวจนิยามขอบเขต |
| ศุกร์ | 27° | 17° | ขัดแย้ง/รอยืนยัน |
| เสาร์ | 21° | 6° | ขัดแย้ง/รอยืนยัน |
| ราหู | 1° | 8° | ขัดแย้ง/รอยืนยัน |

หลักเพิ่มเติมที่ต้นฉบับระบุ: ดาวนิจจะไม่เป็นนิจเมื่อองศาสูงกว่ากำลังของดาวคู่ธาตุ; ถ้าองศาต่ำกว่ากำลังดาวคู่ธาตุถือเป็นนิจ และเท่าค่าจำกัดถือเป็นนิจต่ำสุด อย่างไรก็ตาม ยังไม่ทราบความหมายเชิงเทคนิคที่แน่นอนของ “กำลังดาวคู่ธาตุ” และค่าที่อ้างถึง จึงห้ามนำไปเขียนเป็นสูตรก่อนตรวจตารางต้นฉบับ

ต้นฉบับยังให้ข้อสังเกตเกี่ยวกับพุธเป็น “เก้าแก่ลัคน์” เมื่อพุธเป็นประ/นิจ/กาลี/จุดดับ และกรณีพฤหัสกุมลัคนาหรือเป็นห้าแก่ลัคนา รวมถึงรายการคุณสมบัติที่อาจช่วยให้พุธเด่น เช่น เดช ศรี มนตรี เกษตร อุจ มะจักร และราชาโชค ข้อความเหล่านี้ควรเก็บเป็นกฎพยากรณ์แยกต่างหาก และต้องยืนยันความหมายของ “เก้า” และเงื่อนไขภพก่อนนำไปใช้

## 13. หลักการใช้งานใน HORA

1. ไม่เปลี่ยนสูตรตำแหน่งดาวหรือลัคนาจากเนื้อหาพยากรณ์นี้
2. แยกข้อมูลเป็นสามชั้น: ตำแหน่งดาว, การจัดประเภทมาตรฐาน, และคำอธิบายพยากรณ์
3. สถานะที่ยังไม่ยืนยันต้องแสดงเป็นรอยืนยัน ห้าม hard-code
4. คำพยากรณ์ด้านสุขภาพ รูปร่าง เพศ ความสัมพันธ์หรือชะตาชีวิตไม่ควรแสดงเป็นข้อเท็จจริงหรือคำตัดสินแน่นอน
5. ไม่มีการอ้างว่าเอกสารนี้ครอบคลุมทุกสำนัก และไม่มีรายการอ้างอิงเว็บไซต์


## 14. ภาพรวม 12 ราศี ธาตุ ดาวประจำราศี และคำอธิบายบุคลิก — ข้อมูลที่ผู้ใช้ส่งเพิ่ม 2026-10-10

ส่วนนี้เป็นข้อความภาพรวมเชิงพยากรณ์ที่ผู้ใช้ส่งมา เก็บไว้เป็นเนื้อหาความรู้สำหรับโครงการ ไม่ใช้แทนตารางตำแหน่งมาตรฐานดาว และไม่ใช้คำนวณลัคนาหรือสมผุส

| ๓ อังคาร | ความกล้า ความขยัน โทสะ และอุบัติเหตุ |
| ๔ พุธ | คำพูด สติปัญญา การสื่อสาร และการค้า |
| ๕ พฤหัสบดี | ปัญญา คุณธรรม ครู ผู้ใหญ่ และโชคลาภ |
| ๖ ศุกร์ | ความรัก เงินทอง ความสุข และศิลปะ |

| ๐ มฤตยู | การเปลี่ยนแปลงฉับพลัน เทคโนโลยี และความแปลกใหม่ |

คำเหล่านี้เป็นคำสำคัญสำหรับเนื้อหาอธิบาย ไม่ใช่กฎคำนวณ และไม่ควรแสดงเป็นคำตัดสินชีวิตแบบแน่นอน

### 14.4 ราศีทั่วไปกับลัคนา

บันทึกหลักการตามต้นฉบับ: คำอธิบายราศีทั่วไปเป็นภาพรวมกว้าง ส่วนการผูกดวงตามแนวทางโหราศาสตร์ไทยให้ใช้ลัคนาและตำแหน่งดาวที่คำนวณจากข้อมูลเกิด ไม่ใช่ใช้วันเกิดอย่างเดียว

ข้อมูลที่ต้องขอเพื่อผูกดวง:
1. วัน เดือน ปีเกิด (ระบุ พ.ศ. หรือ ค.ศ. ให้ชัด)
2. เวลาเกิด (ชั่วโมงและนาที; แจ้งหากเป็นเวลาโดยประมาณ)
3. จังหวัด/ประเทศที่เกิด เพื่อกำหนดพิกัดและเขตเวลา

ตัวเลขความแม่นยำ “มากกว่า 70%” ที่ต้นฉบับกล่าวถึงยังไม่มีวิธีวัดหรือหลักฐานตรวจสอบในเอกสาร จึงไม่ควรนำเสนอเป็นค่าความแม่นยำที่รับประกัน

### 14.5 ข้อกำหนดการนำไปใช้ใน HORA

- เก็บเป็นเนื้อหาความรู้/คำอธิบายแยกจากเครื่องคำนวณดาราศาสตร์และตารางมาตรฐานดาว
- ไม่แก้สูตรราศี ลัคนา หรือสูตรดาวจากข้อความนี้
- ช่วงวันและชื่อดาวประจำราศีให้เป็นข้อมูลอ้างอิงชั่วคราวจนกว่าจะยืนยันว่าตรงกับระบบจักรราศีและตำราหลักของ HORA
- หากทำหน้าผูกดวง ให้ระบุว่าต้องใช้วันเดือนปีเกิด เวลาเกิด และสถานที่เกิด; อย่ารับประกันเปอร์เซ็นต์ความแม่นยำจากข้อความนี้
