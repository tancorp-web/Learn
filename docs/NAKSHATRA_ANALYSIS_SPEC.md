# NAKSHATRA_ANALYSIS_SPEC

สถานะ: Draft v1.0 — ฐานข้อมูลโครงสร้างสร้างแล้ว; ยังไม่พร้อมใช้เป็นคำพยากรณ์ production

## วัตถุประสงค์
ใช้ลองจิจูดดาวจริงที่ HORA คำนวณจากระบบสุริยยาตร์ เพื่อจัดดาวเข้าฤกษ์ 27 และบาท 108 จากนั้นเชื่อมฐานความรู้ที่มีแหล่งอ้างอิง โดยไม่เปลี่ยนสูตรคำนวณดาวเดิม

## ข้อกำหนดหลัก
- วงกลม 360 องศา, 27 ฤกษ์ ฤกษ์ละ 13°20′ (800 ลิปดา)
- 4 บาทต่อฤกษ์ บาทละ 3°20′ (200 ลิปดา), รวม 108 บาท
- normalize longitude ให้อยู่ในช่วง [0,360)
- ใช้ช่วง [start,end) ต้นช่วงรวม ปลายช่วงไม่รวม
- ห้ามปัดเศษก่อนคำนวณฤกษ์/บาท
- สูตร: nakshatraIndex=floor(L/(40/3)); padaIndex=floor((L-nakshatraIndex*(40/3))/(10/3)); globalPada=nakshatraIndex*4+padaIndex+1
- เจ้าเรือนราศีคำนวณจากราศีจริงขององศาดาว ไม่กำหนดเจ้าเรือนคงที่ให้ฤกษ์ที่คร่อมราศี

## ต้องแยกข้อมูลคนละระบบ
1. ฤกษ์ 27 กลุ่ม
2. บาท 108
3. ประเภทฤกษ์ 9 (ลำดับวนซ้ำตามตารางที่ผู้ใช้ให้)
4. ดาวเจ้าฤกษ์
5. ดาวเจ้าเรือนราศี

ห้ามใช้คำว่าเจ้าฤกษ์แทนเจ้าเรือน และห้ามอนุมานดาวเจ้าฤกษ์จากประเภทฤกษ์ 9

## การใช้ข้อมูลต้นฉบับ
แหล่งหลัก: “๒๗ กลุ่มดาวฤกษ์กับอาชีพและการดำเนินชีวิตของคุณ” โดย อ.ยอดธง ทับทิวไม้, https://27mean.blogspot.com/

การอ่านหน้าเว็บผ่านตัวดึงข้อมูลได้ไม่ครบ เนื้อหาที่ค้นพบมีบางส่วนและมีภาพประกอบ/ช่วงข้อความขาด อีกทั้งตัวสะกดบางชื่อแตกต่างจากตารางที่ผู้ใช้ให้ จึง:
- เก็บชื่อจากตารางผู้ใช้เป็น canonical ชั่วคราว และเก็บชื่อสะกดต่างไว้ใน sourceNameVariants
- ตั้งดาวเจ้าฤกษ์เป็น provisional ตามลำดับ 9 ดาวที่พบในต้นฉบับช่วงต้นและรอการยืนยันครบ 27
- ยังไม่ถอดคำพยากรณ์ที่ไม่ครบลงเป็นข้อเท็จจริง
- แยก metadata สมัยใหม่ เช่น วันเกิด สี ธาตุ คู่ฤกษ์ สัญลักษณ์ และคนดัง ออกจากข้อมูลคำนวณ
- ใช้การสรุป/ถอดความแทนการคัดลอกเนื้อหายาว และตรวจสิทธิ์ก่อนเผยแพร่

## โครงสร้างไฟล์ข้อมูล
- data/nakshatra-27-reference.json — 27 ฤกษ์ ช่วงองศา ประเภทฤกษ์ 9 และ segment ราศี
- data/nakshatra-108-padas.json — 108 บาท คำนวณจากช่วง 200 ลิปดา
- data/nakshatra-interpretations.json — ช่องข้อมูลคำอธิบายพร้อมสถานะความครบถ้วน
- data/nakshatra-sources.json — แหล่งที่มาและข้อจำกัด

สถานะข้อมูล: verified / partial / pending / missing / conflict
ห้ามนำ missing หรือ pending ไปแสดงเสมือนเป็นคำพยากรณ์ยืนยันแล้ว

## ขั้นตอนวิเคราะห์
1. รับตำแหน่งจาก HORA โดยไม่คำนวณดาวซ้ำ
2. normalize longitude
3. คำนวณราศีและองศาในราศี
4. คำนวณฤกษ์และบาท
5. อ่านประเภทฤกษ์ 9, ดาวเจ้าฤกษ์ และเจ้าเรือนจาก reference ที่ยืนยันแล้ว
6. ดึงคำอธิบาย/อาชีพ พร้อมแหล่งอ้างอิงและสถานะ
7. หากข้อมูลไม่ครบ ให้แสดง “รอตรวจสอบข้อมูล”

ระยะเริ่มต้นให้แสดงผลรายดาวก่อน ยังไม่ให้คะแนนดี/เสียหรือสังเคราะห์บุคลิกทั้งดวงโดยไม่มีกฎที่อนุมัติ

## QA ที่ต้องผ่าน
- ทดสอบจุดเริ่มต้นฤกษ์ 27 จุดและบาท 108 จุด ทั้งค่าก่อน/ตรง/หลังเส้นแบ่ง
- 0° และ 360° ต้องให้ผลเดียวกัน
- ไม่มีช่องว่างหรือช่วงซ้อน; ทุกฤกษ์มี 4 บาท
- ตรวจฤกษ์ที่คร่อมราศีและคำนวณเจ้าเรือนจากตำแหน่งจริง
- ตรวจดาวทุกดวงที่ HORA ส่งมา รวมราหู เกตุ และมฤตยู
- ตรวจว่า reference ไม่เปลี่ยนลองจิจูดต้นทาง
