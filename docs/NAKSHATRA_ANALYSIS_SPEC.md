# NAKSHATRA_ANALYSIS_SPEC

สถานะ: Draft v2.1 — ขอบเขต 27mean-only; ความหมายยัง partial/missing

## แหล่งข้อมูล
ใช้เฉพาะบทความ 27mean “๒๗ กลุ่มดาวฤกษ์กับอาชีพและการดำเนินชีวิตของคุณ” โดย อ.ยอดธง ทับทิวไม้: https://27mean.blogspot.com/
ไม่ใช้คัมภีร์หรือศาสตร์อื่น และไม่สังเคราะห์ความหมายดาวทั้ง 9

## การคำนวณ lookup
ใช้ longitude ที่ HORA Suriyayatra engine คำนวณเท่านั้น
วงกลม 21600 ลิปดา, 27 ฤกษ์ × 800 ลิปดา, 4 บาทต่อฤกษ์ × 200 ลิปดา
ช่วง [start,end), normalize longitude, ไม่ปัดเศษก่อน lookup
ห้ามใช้ Lahiri/Tropical หรือคำนวณตำแหน่งดาวซ้ำในชั้นความหมาย

## การแสดงความหมาย
แสดงความหมายทางนามธรรม/จิตวิทยา บุคลิก จุดเด่น ข้อควรระวัง อาชีพ และ metadata ที่พบใน 27mean เท่านั้น
แยกความหมายทั่วไปออกจากข้อมูลประกอบสมัยใหม่
ความหมายรายบาทแสดงเมื่อบทความระบุบาทชัดเจนเท่านั้น
ไม่อนุมานจากราศี ดาวเจ้าเรือน ภพ เทพ หรือแหล่งอื่น
ข้อมูล partial ต้องมีคำเตือน; missing ให้แสดง “รอตรวจสอบข้อมูล”

## สถานะ
partial = พบข้อความบางส่วนจากบทความ/ดัชนี แต่ยังตรวจต้นฉบับเต็มไม่ครบ
missing = ยังไม่มีข้อความเพียงพอ
verified = ตรวจต้นฉบับเต็มและยืนยันฟิลด์แล้ว
conflict = ต้นฉบับขัดกัน

## QA
ตรวจ 27 ช่วง × 800 ลิปดา และ 108 ช่วง × 200 ลิปดา ต่อเนื่องไม่มีช่องว่าง/ซ้อน
ทุกความหมายต้องมี sourceId SRC-27MEAN-ARTICLE
ห้ามเติมข้อมูลที่ไม่มีหลักฐาน
ห้ามเปลี่ยนสูตร/ตำแหน่งดาว HORA
