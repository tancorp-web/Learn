# NAKSHATRA_ANALYSIS_SPEC

สถานะ: Draft v2.0 — โครงสร้าง 27/108 จัดระเบียบแล้ว; ความหมายยังต้องตรวจต้นฉบับ 27mean ให้ครบก่อนใช้งานจริง

## วัตถุประสงค์
ใช้ลองจิจูดที่ HORA คำนวณจากสุริยยาตร์เพื่อระบุฤกษ์ 27 และบาท 108 จากนั้นแสดงเฉพาะความหมายที่ตรวจสอบได้จาก 27mean.blogspot.com เท่านั้น

## ขอบเขตแหล่งความรู้
- แหล่งความหมายเพียงแหล่งเดียว: 27mean, “๒๗ กลุ่มดาวฤกษ์กับอาชีพและการดำเนินชีวิตของคุณ” โดย อ.ยอดธง ทับทิวไม้
- ไม่ใช้ Bṛhat Jātaka, Bṛhat Parāśara, Bṛhat Saṃhitā หรือคัมภีร์อื่น
- ไม่ใช้ความหมายดาวแบบพระเวท/Jyotish จากแหล่งอื่น
- ไม่สังเคราะห์ความหมายดาวทั้ง 9 และไม่สร้างคำพยากรณ์จากธรรมชาติดาว
- ข้อมูลจากผู้ใช้ที่ยังตรวจสอบกับ 27mean ไม่ได้ ให้พักเป็น pending และไม่นำไปแสดงเป็นคำพยากรณ์

## ขอบเขตการคำนวณ
- วงกลม 360 องศา แบ่ง 27 ฤกษ์ ฤกษ์ละ 13°20′ หรือ 800 ลิปดา
- แต่ละฤกษ์แบ่ง 4 บาท บาทละ 3°20′ หรือ 200 ลิปดา รวม 108 บาท
- normalize longitude ให้อยู่ในช่วง [0,360)
- ใช้ช่วง [start,end): รวมจุดเริ่ม ไม่รวมจุดสิ้นสุด
- ห้ามปัดเศษก่อนค้นหาฤกษ์และบาท
- สูตร: nakshatraIndex=floor(L/800); padaIndex=floor((L mod 800)/200); globalPada=nakshatraIndex*4+padaIndex+1 เมื่อ L มีหน่วยเป็นลิปดาจาก 0°
- ตำแหน่งดาวต้องรับจาก HORA Suriyayatra engine เท่านั้น ห้ามคำนวณซ้ำหรือแปลง Lahiri/Tropical

## การใช้ความหมาย
1. ระบุฤกษ์จาก longitude จริงของ HORA
2. ระบุบาทจากช่วง 200 ลิปดา
3. แสดงความหมายทั่วไปของฤกษ์จาก 27mean เมื่อมีหลักฐาน
4. แสดงความหมายเฉพาะบาทเฉพาะเมื่อ 27mean ระบุไว้ชัดเจน
5. อาชีพ จุดเด่น ข้อควรระวัง และข้อมูลประกอบ แสดงเฉพาะฟิลด์ที่ตรวจสอบแหล่งได้
6. หากข้อมูลไม่ครบ ให้แสดง “รอตรวจสอบข้อมูล” ห้ามอนุมานจากราศี ดาว เจ้าเรือน เทพ หรือศาสตร์อื่น

## สถานะข้อมูล
- verified: ตรวจข้อความต้นฉบับได้ตรงฟิลด์
- partial: มีข้อความบางส่วน แต่ยังไม่ครบ
- pending: รอตรวจต้นฉบับ
- missing: ยังไม่มีข้อมูลที่ใช้ได้
- conflict: ต้นฉบับมีข้อมูลขัดกัน ต้องให้ผู้ใช้ตัดสินก่อน

## ไฟล์

- data/nakshatra-108-padas.json: ช่วงองศา 108 บาทสำหรับ lookup เท่านั้น ไม่ใช่ความหมาย
- data/nakshatra-interpretations.json: ความหมายจาก 27mean เท่านั้น
- data/nakshatra-sources.json: แหล่งที่มาและข้อจำกัด

## QA
- 27 ฤกษ์ครบและแต่ละช่วง 800 ลิปดา
- 108 บาทครบและแต่ละช่วง 200 ลิปดา
- ไม่มีช่องว่างหรือช่วงซ้อน; ช่วงแรกเริ่ม 0 และช่วงสุดท้ายสิ้นสุด 21600
- ทุกขอบเขตทดสอบค่าก่อน/ตรง/หลัง
- 0° และ 360° ให้ผลเท่ากัน
- ไม่มีข้อความความหมายที่ไม่มี sourceId 27mean
- ไม่มีคำอธิบายบาทที่ไม่ได้ระบุในต้นฉบับ
- การจัดการความรู้ไม่แก้ตำแหน่งดาวหรือสูตรสุริยยาตร์
