# แหล่งอ้างอิงมาตรฐานดาว: บ้านคุณยายกลิ่นโสม

วันที่อ่าน: 2026-10-10

แหล่งต้นทาง: https://www.baankhunyai.com/17432048/%E0%B8%94%E0%B8%B2%E0%B8%A7%E0%B8%A1%E0%B8%B2%E0%B8%95%E0%B8%A3%E0%B8%B2%E0%B8%90%E0%B8%B2%E0%B8%99

เอกสารนี้ถอดความจากบทความ “ดาวมาตราฐาน” ของคุณยายกลิ่นโสม เป็นระบบอ้างอิงของผู้เขียนรายหนึ่ง ไม่ใช่ข้อสรุปสากลของโหราศาสตร์ไทย ห้ามผสมกับตารางสำนักอื่นโดยไม่ระบุที่มา และห้ามนำไปเปลี่ยนสูตรคำนวณดาราศาสตร์ของ HORA โดยอัตโนมัติ

## แนวคิดที่บทความระบุ
- มาตรฐานดาวบอกกำลัง/ความอ่อนของดาวเมื่ออยู่ในราศีต่าง ๆ; โหราศาสตร์ไทยยังอาจพิจารณานวางค์และตรียางค์
- ผู้เขียนย้ำว่าต้องอ่านภพ/เรือนประกอบ และไม่ใช้มาตรฐานดาวทุกชนิดในการอ่านดวงสไตล์ของตน
- เกษตรเปรียบเหมือนเจ้าของบ้าน มั่นคงและมีกำลังเต็มที่
- ประ/ปรเกษตรอยู่ตรงข้ามเรือนเกษตรในระบบนี้ สื่อถึงความอ่อนกำลังและความไม่มั่นคง
- อนุเกษตร/เกษตรสลับเรือนให้ผลรองลงมา และต้องตรวจความเป็นไปได้จริงจากการเดินของดาว
- อุจหมายถึงสูงส่งและมีกำลังมาก; นิจอยู่ตรงข้ามอุจ
- ราชาโชคเน้นความนิยม เมตตา การยกย่องและผู้สนับสนุน แต่ต้องอ่านภพประกอบ
- มหาจักรอาจให้ผลโดดเด่น/ผาดโผนทั้งคุณและโทษ; จุลจักรอยู่ตรงข้ามมหาจักรและให้ผลน้อยกว่า
- อุจจาภิมุขเป็นตำแหน่ง “อยู่หน้าดาวอุจ” และมีกำลังอ่อนกว่าอุจ
- เทวีโชคอยู่ฝั่งตรงข้ามราชาโชคและให้คุณน้อยกว่า
- อุจจาวิลาสถูกอธิบายว่า “ดาวที่อยู่หลังอุจ” แต่บทความหน้านี้ไม่ได้ให้ตารางรายดาวครบถ้วน

- อาทิตย์ (๑): สิงห์
- จันทร์ (๒): กรกฎ

- พุธ (๔): เมถุน, กันย์
- พฤหัสบดี (๕): ธนู, มีน
- ศุกร์ (๖): พฤษภ, ตุล

## ข้อควรระวังและสถานะ
- ค่าที่ซ้อนกันและชื่อที่ดูขัดกันเก็บไว้ตามบทความ ไม่แก้เองให้ตารางดูสอดคล้อง
- บทความนี้ไม่มีตารางองศาจุดอุจ/นิจแบบเฉพาะองศา และไม่มีตารางอุจจาวิลาสรายดาวที่ครบถ้วน จึงห้ามอนุมานหรือสร้างค่าเพิ่มเอง
- ข้อมูลนี้เป็นความรู้ประกอบการศึกษา ยังไม่ใช่กฎคำนวณ ไม่ได้ถูกนำไปใช้คำนวณดวงหรือให้คะแนนดาวในแอป
- ก่อนนำไปใช้จริง ต้องยืนยันกับผู้ใช้ว่าเลือกแนวทางของแหล่งนี้ และแยกแหล่งอ้างอิง/สำนักในข้อมูลทุกค่า
- ห้ามแก้สูตรดาว ลัคนา หรือ index2.html จากเอกสารนี้เพียงอย่างเดียว
