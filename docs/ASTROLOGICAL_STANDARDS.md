# มาตรฐานดาวโหราศาสตร์ไทย — บันทึกความรู้โครงการ HORA

เอกสารนี้เป็นบันทึกภายในโครงการสำหรับออกแบบและตรวจสอบการแสดงมาตรฐานดาว ไม่ใช่คำยืนยันว่าตารางทุกสำนักเหมือนกัน ข้อมูลส่วนที่ยังไม่ได้ยืนยันกับตารางมาตรฐานของผู้ใช้ให้ถือเป็น **เกณฑ์เบื้องต้น** และห้ามนำไปฝังเป็นกฎตายตัวในระบบจนกว่าจะตกลงแหล่งมาตรฐานหลัก

## หลักการสำคัญของระบบ

1. แยกการคำนวณตำแหน่งดาวทางดาราศาสตร์ออกจากการตัดสินมาตรฐานดาวอย่างเด็ดขาด
2. ใช้ราศีและองศาที่ระบบ HORA คำนวณได้อยู่แล้วเป็นข้อมูลนำเข้า ห้ามแก้สูตรตำแหน่งดาว ลัคนา หรือเครื่องยนต์ดาราศาสตร์เพื่อให้ผลมาตรฐานดาวตรงกับความคาดหวัง
3. สถานะมาตรฐานดาวเป็นผลการจัดประเภทตามตาราง/กฎที่กำหนด ไม่ใช่สูตรคำนวณตำแหน่งดาว
4. ดาวหนึ่งดวงอาจตรงเงื่อนไขมาตรฐานมากกว่าหนึ่งประเภทได้ ระบบต้องเก็บและแสดงทุกสถานะที่เข้าเงื่อนไข ไม่ควรบังคับให้เหลือสถานะเดียว เว้นแต่กฎของสำนักนั้นระบุชัด
5. ทุกผลต้องตรวจสอบย้อนกลับได้: ชื่อดาว ตำแหน่งราศี/องศา ชื่อมาตรฐาน กฎที่ใช้ และผลตรวจ
6. ไม่ผสมตารางจากหลายสำนักโดยไม่ระบุ และไม่เดาค่าที่ไม่มีข้อมูลยืนยัน
7. การเพิ่มหรือปรับความรู้เรื่องมาตรฐานดาวต้องไม่แก้ `index2.html` และต้องไม่เปลี่ยนสูตรดาวเดิมโดยไม่ได้รับอนุญาตเฉพาะเจาะจง

## คำศัพท์และความหมายเบื้องต้น

- **เกษตร**: ดาวอยู่ในราศีที่ถือเป็นเรือนของตนตามตารางมาตรฐาน
- **ประ / ประเกษตร**: ในระบบที่ใช้ความหมายนี้ หมายถึงราศีตรงข้ามกับราศีเกษตรของดาว ต้องตรวจรูปแบบคำและกฎตามตารางหลักของโครงการ
- **อุจจ์**: ตำแหน่งราศีที่กำหนดให้ดาวได้มาตรฐานอุจจ์
- **นิจ**: ตำแหน่งราศีตรงข้ามกับอุจจ์ในตารางมาตรฐานที่ใช้กันทั่วไป
- **อุจจาวิลาส**: มาตรฐานแยกต่างหาก ห้ามใช้แทนคำว่าอุจจ์ และห้ามอนุมานจากการอยู่ราศีอุจจ์โดยไม่มีตารางกฎ
- **อุจจาภิมุข**: มาตรฐานแยกต่างหาก ต้องมีตาราง/เงื่อนไขเฉพาะ ไม่ถือว่าเป็นชื่อพ้องของอุจจ์หรืออุจจาวิลาส
- **ราชาโชค**: มาตรฐานที่ต้องตรวจตามเกณฑ์เฉพาะของดาวและราศี ไม่ใช่คำพ้องของเกษตรหรืออุจจ์
- **มหาจักร**: มาตรฐานอีกประเภทหนึ่ง ต้องใช้ตารางเฉพาะ
- **จุลจักร**: มาตรฐานอีกประเภทหนึ่ง ต้องใช้ตารางเฉพาะ ไม่อนุมานว่าเป็นคู่ตรงข้ามของมหาจักร เว้นแต่ตารางหลักที่ตกลงระบุเช่นนั้น
- **เทวีโชค**: มาตรฐานอีกประเภทหนึ่ง ต้องมีเกณฑ์เฉพาะที่ยืนยันแล้ว
- **มูลเกษตร**: มาตรฐาน/สถานะที่ต้องตรวจนิยามและตารางของสำนักหลักแยกจากเกษตรทั่วไป
- **มาตรฐานอื่น ๆ**: ต้องเพิ่มเป็นกฎแยกชื่อชัดเจน ไม่รวมหลายสถานะไว้ในกฎเดียวโดยไม่จำเป็น

คำอธิบายนี้กำหนดแนวทางจัดข้อมูลเท่านั้น ไม่ใช่คำทำนาย และไม่ได้หมายความว่าทุกสำนักจะใช้คำนิยามหรือรายชื่อมาตรฐานเหมือนกันทั้งหมด

## ตารางเบื้องต้นสำหรับดาว ๑–๗

ตารางต่อไปนี้เป็นชุดอ้างอิงเบื้องต้นที่พบใช้ทั่วไปในโหราศาสตร์ไทย/โหราศาสตร์ดั้งเดิม ต้องยืนยันกับตารางมาตรฐานที่เจ้าของโครงการเลือกก่อนนำไปใช้จริง

| ดาว | ราศีเกษตรเบื้องต้น | ราศีอุจจ์เบื้องต้น | ราศีนิจเบื้องต้น |
|---|---|---|---|
| ๑ อาทิตย์ | สิงห์ | เมษ | ตุล |
| ๒ จันทร์ | กรกฎ | พฤษภ | พิจิก |
| ๓ อังคาร | เมษ, พิจิก | มังกร | กรกฎ |
| ๔ พุธ | เมถุน, กันย์ | กันย์ | มีน |
| ๕ พฤหัสบดี | ธนู, มีน | กรกฎ | มังกร |
| ๖ ศุกร์ | พฤษภ, ตุล | มีน | กันย์ |
| ๗ เสาร์ | มังกร, กุมภ์ | ตุล | เมษ |

### ข้อควรระวังของตารางเบื้องต้น

- ตารางนี้ระบุเฉพาะเกษตร อุจจ์ และนิจเบื้องต้นเท่านั้น ไม่ได้ให้ค่าของราชาโชค มหาจักร จุลจักร อุจจาวิลาส อุจจาภิมุข เทวีโชค หรือมูลเกษตร
- อย่านำกฎดาว ๑–๗ ไปใช้กับราหู เกตุ หรือมฤตยูโดยอัตโนมัติ
- สำหรับเกษตรหลายราศีของดาวพุธและดาวศุกร์ ต้องคงทั้งสองราศีตามตาราง ไม่ทำให้เหลือราศีเดียว
- ราศีอุจจ์/นิจในตารางนี้เป็นการจัดประเภทระดับราศี ไม่ใช่การตรวจองศาอุจจ์สูงสุดหรือเกณฑ์ย่อยที่อาจใช้ในบางตำรา
- หากตารางมาตรฐานหลักของโครงการกำหนดต่างออกไป ให้แก้เอกสารและกฎตามตารางที่ผู้ใช้ยืนยัน โดยบันทึกความแตกต่างให้ตรวจสอบได้

## โครงสร้างข้อมูลที่แนะนำ

ควรเก็บกฎแต่ละมาตรฐานแยกกัน เช่น:

- `standard_key`: รหัสมาตรฐานที่ไม่ซ้ำ
- `display_name_th`: ชื่อภาษาไทยที่จะแสดง
- `planet_ids`: ดาวที่กฎนี้ใช้ได้
- `sign_ids`: ราศีหรือเงื่อนไขตำแหน่งที่ทำให้ผ่าน
- `degree_rule`: เงื่อนไของศา ถ้ามีและมีแหล่งยืนยัน
- `rule_status`: confirmed หรือ provisional
- `rule_note`: คำอธิบายกฎและข้อยกเว้น
- `reference_label`: ชื่อ/รุ่นของตารางมาตรฐานที่โครงการตกลงใช้ (ไม่จำเป็นต้องเป็น URL)

ผลตรวจของดาวแต่ละดวงควรรองรับรายการสถานะหลายรายการ และแยกผล “ตรงตามกฎ” ออกจากคำแปลความหมายเชิงพยากรณ์

## วิธีตรวจสอบก่อนนำขึ้นใช้งาน

1. ตกลงตารางมาตรฐานหลักกับเจ้าของโครงการ
2. จัดทำ test cases ที่มีดาวและราศีตัวอย่างสำหรับทุกมาตรฐาน รวมกรณีขอบเขตองศาถ้ามีกฎองศา
3. ทดสอบกรณีที่ดาวหนึ่งดวงได้หลายสถานะ และกรณีไม่มีสถานะตามกฎที่รองรับ
4. เปรียบเทียบผลกับตารางที่ยืนยันแล้วและบันทึก PASS/FAIL พร้อมเหตุผล
5. ตรวจ diff ให้แน่ใจว่าเปลี่ยนเฉพาะเอกสารหรือโมดูลมาตรฐานดาวที่ได้รับอนุญาต ไม่แตะสูตรคำนวณตำแหน่งดาว
6. อย่าอ้างว่าถูกต้องครบทุกสำนักจนกว่าตารางและชุดทดสอบจะครอบคลุมตามขอบเขตที่ตกลง

## สถานะเอกสาร

- เป็นบันทึกความรู้ภายในโครงการ ไม่ใส่รายการอ้างอิงเว็บไซต์
- เกณฑ์เกษตร/อุจจ์/นิจของดาว ๑–๗ ในตารางเป็นข้อมูลเบื้องต้นที่ต้องยืนยันก่อนใช้งานจริง
- เกณฑ์ของอุจจาวิลาส อุจจาภิมุข ราชาโชค มหาจักร จุลจักร เทวีโชค มูลเกษตร และมาตรฐานอื่น ยังไม่กำหนดเป็นค่าตายตัวจนกว่าจะได้รับตารางหลักที่ยืนยัน
- ไม่มีการแก้สูตรคำนวณดาวหรือลัคนาในเอกสารนี้
