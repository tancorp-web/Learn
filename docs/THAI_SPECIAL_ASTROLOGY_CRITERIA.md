# คลังเกณฑ์พิเศษโหราศาสตร์ไทยของ HORA

อัปเดต: 2026-10-10  
สถานะรวม: **DISCOVERY / REFERENCE ONLY**  
ไฟล์ข้อมูล: `js/data/thai-special-criteria.js`  
ชุดทดสอบ: `qa/formula-tests/thai-special-criteria.test.js`

เอกสารนี้เป็นคลังรวบรวมชื่อและสูตรเบื้องต้นเพื่อให้อาจารย์แทนแยกประเภทและตรวจสอบ ไม่ใช่การรับรองว่าทุกเกณฑ์เป็นมาตรฐานเดียวกันทุกสำนัก และไม่ใช่การเปิดคำพยากรณ์อัตโนมัติ

## 1. กติกาการเก็บข้อมูล

- เก็บชื่อเกณฑ์ รหัสคงที่ หมวด เงื่อนไขดาว/ราศี/ภพ สถานะ และข้อขัดแย้งแยกจากเครื่องคำนวณใน `main.js`
- ห้ามเปลี่ยนสูตรตำแหน่งดาว ลัคนา หรือเวลาในงานนี้
- คำว่า “ดาวใดก็ได้” ใช้เฉพาะเมื่อแหล่งที่พบไม่ได้บังคับดาวเฉพาะดวง ไม่ได้หมายความว่าทุกสำนักยอมรับเหมือนกัน
- ถ้าสูตรยังไม่ครบ ให้ใช้ `NEEDS_SOURCE` หรือ `SOURCE_VARIANT` และ `execution: DISABLED`/ `REFERENCE_ONLY`; ห้ามสร้างสูตรเพื่อให้ดูครบ
- ตำแหน่งภพต้องคำนวณจากลัคนาและผังของดวงนั้น ห้ามกำหนดภพเป็นคุณสมบัติถาวรของดาว
- คำพยากรณ์ที่เป็นความเชื่อไม่ใช่ข้อยืนยันทางวิทยาศาสตร์

## 4. ความสัมพันธ์ดาวที่มีไฟล์แยกอยู่แล้ว

กฎ กุม, ทับ, เล็ง, โยคหน้า/โยคหลัง, ตรีโกณ, จตุโกณ และฉาก อยู่ใน `js/data/planetary-relations.js` แยกจากคลังเกณฑ์ชื่อเฉพาะแล้ว

- ความสัมพันธ์แบบนับราศีและการวัดมุมองศาต้องแยกกัน
- “ทับ” ต้องระบุว่าเป็นดาวจรเทียบดาวเดิม/ลัคนา หรือการอยู่ร่วมราศีในบริบทอื่น
- “จตุโกณ” และ “จตุสดัย” อาจใช้ต่างความหมายตามตำรา จึงไม่ควรถือเป็นคำพ้องสากล
- นำพล/ขับพลยังคงรอตรวจสูตรและไม่เปิดใช้; ไม่ถือว่าเท่ากับนำผล/ตามผล

## 5. สถานะการใช้งานในโปรเจกต์

- ไฟล์ใหม่เป็นคลังอ้างอิงที่ import ใช้ต่อได้ แต่ยังไม่เชื่อมเข้ากับหน้า UI และไม่เปลี่ยนคำพยากรณ์
- รายการที่เป็น `REFERENCE_ONLY` มีข้อมูลให้ตรวจ แต่ไม่ควรถือเป็นผลสรุปอัตโนมัติ
- รายการที่เป็น `DISABLED` ยังไม่มีสูตรที่ยืนยันได้
- ก่อนเปิดใช้แต่ละกฎ ต้องมีแหล่งมาตรฐานที่อาจารย์แทนเลือก, เงื่อนไขครบถ้วน, ตัวอย่างดวงทดสอบ, ผลที่คาดหวัง และการทดสอบถดถอย
- ห้ามแก้สูตรดาวที่ล็อกไว้หรือสูตรลัคนาเพียงเพื่อให้ผลเกณฑ์ตรงกับตัวอย่างใดตัวอย่างหนึ่ง
