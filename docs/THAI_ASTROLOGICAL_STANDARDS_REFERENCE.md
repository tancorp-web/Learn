# บันทึกอ้างอิงดวงมาตรฐานและคำพยากรณ์ดาว — HORA

เอกสารนี้จัดระเบียบเนื้อหาที่ผู้ใช้ส่งมาเกี่ยวกับดวงมาตรฐานดาวและความหมายเชิงพยากรณ์ เพื่อใช้เป็นฐานความรู้ในการพัฒนาระบบ HORA เท่านั้น เนื้อหาเป็นบันทึกตามแนวทาง/ข้อความต้นฉบับที่ผู้ใช้ให้มา ไม่ใช่การรับรองว่าทุกข้อเป็นมาตรฐานสากลหรือใช้ตรงกันทุกสำนัก

## ข้อกำหนดการนำไปใช้

- แยก **การคำนวณตำแหน่งดาว** ออกจาก **การจัดประเภทดวงมาตรฐาน** และ **คำแปลความหมายพยากรณ์** เป็นคนละชั้นข้อมูล
- ห้ามนำข้อความพยากรณ์หรือคำอธิบายไปเปลี่ยนสูตรตำแหน่งดาว ลัคนา หรือเครื่องยนต์ดาราศาสตร์
- ข้อกำหนดที่ยังไม่ชัด เช่น ตำแหน่งราศี/องศาของมาตรฐานเฉพาะ ให้คงสถานะ “รอยืนยัน” ห้ามเดาหรือ hard-code
- ถ้อยคำเกี่ยวกับรูปร่าง เพศ สุขภาพ ความสัมพันธ์ หรือชะตาชีวิตเป็นความเชื่อ/คำพยากรณ์ตามต้นฉบับ ไม่ใช่ข้อเท็จจริงทางวิทยาศาสตร์ และไม่ควรนำเสนอเป็นคำตัดสินแน่นอนเกี่ยวกับบุคคล
- ไม่ใช้เอกสารนี้แทนตารางมาตรฐานหลักที่ผู้ใช้ยืนยัน และไม่ผสมเกณฑ์จากคนละสำนักโดยไม่ระบุ

## 1. กลุ่มดวงมาตรฐานหลัก

| มาตรฐาน | ความหมายตามบันทึกผู้ใช้ | สถานะการนำไปคำนวณ |
|---|---|---|
| เกษตร | ความมั่นคง หลักทรัพย์ ความรู้ วิชาการ และอาชีพ | ต้องยืนยันตารางราศี/ดาวก่อนใช้ |
| ประเกษตร / ประ | ความผันแปร ผิดหวัง อุปสรรค ความล่าช้า หรือผลไม่เป็นไปตามหวัง | ต้องยืนยันว่ากฎนี้หมายถึงราศีตรงข้ามเกษตรในสำนักที่เลือกหรือไม่ |
| อุจจ์ | ความแข็งแกร่งของผลงานและหน้าที่การงาน พลังที่เด่นมาก | ต้องแยกกฎระดับราศีออกจากองศาอุจจ์สูงสุด |
| นิจ | ความเสื่อมกำลัง ความต่ำต้อย อับเฉา หรือผลติดขัด | กฎองศาและข้อยกเว้นที่ผู้ใช้ส่งมายังมีข้อความไม่สอดคล้องกัน ต้องตรวจต้นฉบับก่อนเขียนเป็นสูตร |
| อุจจาวิลาส | การไต่ระดับขึ้นไปสู่จุดสูงสุด; ต้นฉบับอธิบายว่าเป็นตำแหน่งก่อนถึงอุจ/มหาอุจ | ต้องยืนยันวิธีระบุราศีและองศา |
| อุจจาภิมุข | ตำแหน่งถัดจากอุจไปข้างหน้าในจักรราศีตามคำอธิบายต้นฉบับ ให้คุณแต่ลดลงจากอุจจาวิลาส | ต้องยืนยันกฎตามดาวและข้อยกเว้น |
| มหาจักร | ความสง่า ความคล่องแคล่ว อิทธิพลโดดเด่น พลิกแพลง และแคล้วคลาดตามคำพยากรณ์ | ต้องมีตารางแยกตามดาว/ราศี |
| จุลจักร | ตามต้นฉบับคือดาวในราศีตรงข้ามมหาจักร และให้คุณน้อยกว่า โดยอาจต้องมีลัคนา/เกษตรสนับสนุน | อย่าสร้างกฎจากการกลับค่ามหาจักรโดยอัตโนมัติจนกว่าจะยืนยัน |
| ราชาโชค | วาสนา การได้รับความนิยม การอุปถัมภ์ และโอกาสจากผู้ใหญ่/บุคคลอื่น | ต้องมีตารางเฉพาะ |
| เทวีโชค | ตามต้นฉบับคือราศีตรงข้ามราชาโชค และให้คุณน้อยกว่า เว้นแต่มีเงื่อนไขหนุน | ต้องยืนยันตารางและกฎ ไม่อนุมานจากชื่อเพียงอย่างเดียว |

## 2. ความหมายเกษตรแยกตามดาว

สรุปความหมายจากข้อความที่ผู้ใช้ส่งมา โดยคงไว้เป็นคำอธิบายเชิงพยากรณ์ ไม่ใช่ผลคำนวณที่ยืนยันแล้ว

| ดาว | ประเด็นเด่นตามต้นฉบับ |
|---|---|
| ๑ อาทิตย์ | เกียรติยศ ตำแหน่ง อำนาจ ความเป็นผู้นำ ความรักชื่อเสียงและความเป็นอิสระ; ด้านเงาคือดื้อ ถือดี ใจร้อน |
| ๒ จันทร์ | ความนุ่มนวล สุภาพ เสน่ห์ ความเป็นที่รัก ความอุดมสมบูรณ์ และเรื่องมารดา; ด้านเงาคือความเจ้าชู้/ฉวยโอกาสตามคำพยากรณ์เดิม |
| ๓ อังคาร | ความกล้า ขยัน พละกำลัง การตัดสินใจเร็ว งานทหาร/ตำรวจหรือภารกิจที่ต้องเด็ดขาด; ด้านเงาคือใจร้อนและขาดความนิ่มนวล |
| ๔ พุธ | ไหวพริบ การสื่อสาร การพูดเขียน ธุรกิจ การแก้ปัญหา การเรียนรู้เร็ว และการประสานงาน |
| ๕ พฤหัสบดี | การศึกษา ปัญญา คุณธรรม ศาสนา ความยุติธรรม ผู้ใหญ่ ครูอาจารย์ และความอุดมสมบูรณ์; ด้านเงาคือช้าเพราะรอบคอบหรือเน้นทฤษฎี |
| ๖ ศุกร์ | ศิลปะ ความงาม เสน่ห์ ความรัก รสนิยม การเงิน การธนาคาร และงานที่เกี่ยวกับความสวยงาม |
| ๗ เสาร์ | ความอดทน ความเด็ดขาด การต่อสู้ระยะยาว เกษตรกรรม ที่ดิน เครื่องกล และการบริหาร; ด้านเงาคือวิตกกังวลหรือเก็บความโกรธ |
| ๘ ราหู | ไหวพริบ การอ่านคน การปรับตัว เล่ห์เหลี่ยม ลาภผล และการทำงานในสถานการณ์ซับซ้อน; มีคำบรรยายด้านเงาเรื่องอารมณ์และความตระหนี่ |
| ๙ เกตุ | ในต้นฉบับเปรียบคล้ายอาทิตย์แต่รุนแรงกว่า เน้นความดื้อ ความต้องการเอาชนะและการวางตัวโดดเด่น |
| ๐ มฤตยู | ความคิดประดิษฐ์ การค้นคว้า วิทยาศาสตร์ โหราศาสตร์ ความคิดริเริ่ม และการทำงานกับกลุ่ม/สมาคม |
| เนปจูน | จินตนาการ สิ่งลึกลับ การค้นคว้าสิ่งไม่คุ้นเคยและการวางแผนระยะยาว; มีคำเตือนตามต้นฉบับเรื่องความเพ้อฝันและการถูกหลอก |
| พลูโต | การเปลี่ยนแปลง ฟื้นฟู ซ่อมแซม พัฒนาสิ่งเดิมให้ดีขึ้น ความมุ่งมั่นและการสร้างประโยชน์ส่วนรวม |

**หลักพยากรณ์ที่ผู้ใช้ส่งมา:** “ดาวเกษตรต่อเกษตรเล็งกัน” ถูกระบุว่าอาจสัมพันธ์กับทรัพย์สมบัติที่วิบัติภายหลัง ข้อนี้ให้เก็บเป็นคำพยากรณ์ตามต้นฉบับและต้องยืนยันบริบทก่อนนำไปแสดงเป็นกฎอัตโนมัติ

## 3. ความหมายประเกษตรแยกตามดาว

ตามข้อความต้นฉบับ ประเกษตรเน้นความอาภัพ อุปสรรค ความล่าช้า และผลที่ไม่ราบรื่น โดยแจกแจงดังนี้:

- **อาทิตย์:** เรื่องทรัพย์ มิตรสหาย ลาภผล และความสำเร็จอาจติดขัด
- **จันทร์:** เรื่องความสัมพันธ์และหลักฐานความมั่นคงอาจไม่เป็นไปตามหวัง
- **อังคาร:** ความช่วยเหลือจากญาติหรือมิตรอาจมีอุปสรรค
- **พุธ:** ความสัมพันธ์กับญาติ มิตร คู่ครอง หรือบุตรตามคำพยากรณ์เดิมอาจไม่ราบรื่น
- **พฤหัสบดี:** การพึ่งพาครู ผู้ใหญ่ หรือที่ปรึกษาอาจไม่เป็นไปตามหวัง
- **ศุกร์:** ต้นฉบับกล่าวถึงความไม่สมบูรณ์ของร่างกายและปัญหาความรัก/ทรัพย์สิน แต่ไม่ควรใช้เป็นข้อสรุปด้านสุขภาพจริง
- **เสาร์:** มิตรสหายอาจนำความเดือดร้อนหรือภาระมาให้
- **ราหู:** ต้นฉบับกล่าวถึงความขัดแย้ง ความไม่ซื่อตรง และภาพลักษณ์ที่ไม่สง่า

รายการนี้เป็นการย่อคำพยากรณ์จากต้นฉบับ ไม่ใช่คำวินิจฉัยตัวบุคคล และยังไม่ใช่กฎคำนวณตำแหน่งดาว

## 4. ความหมายอุจจ์แยกตามดาว

ต้นฉบับอธิบายอุจจ์ว่าเป็นตำแหน่งสูงส่งและมีพลังมาก ซึ่งอาจให้ทั้งคุณและโทษอย่างเด่นชัด

- **อาทิตย์:** ทรัพย์ ชัยชนะ ความเข้มแข็ง เกียรติ และความรู้
- **จันทร์:** เสน่ห์ ความเป็นที่รัก ทรัพย์ และความอุดมสมบูรณ์
- **อังคาร:** ความกล้า เกียรติ ชัยชนะ และความเด็ดขาด; ระวังโทสะตามคำพยากรณ์
- **พุธ:** ความรู้ ความร่าเริง การเป็นที่นิยม และความคล่องแคล่ว
- **พฤหัสบดี:** ปัญญา คุณธรรม ผู้ใหญ่สนับสนุน การให้อภัย และโชคลาภ
- **ศุกร์:** ทรัพย์ ความสุภาพ ศิลปะ และเมตตา
- **เสาร์:** ความอดทน อำนาจ อายุยืน การสนับสนุน และความมั่นคง
- **ราหู:** ต้นฉบับให้ความหมายคล้ายเสาร์ในด้านความเจริญและทรัพย์

ข้อความต้นฉบับมีหลักเกณฑ์ย่อยเกี่ยวกับองศาอุจ/นิจและดาวคู่ธาตุ ซึ่งต้องตรวจแยกต่างหาก ห้ามแปลงคำอธิบายนี้เป็นกฎองศาโดยอัตโนมัติ

## 5. อุจจาวิลาสและอุจจาภิมุข

### อุจจาวิลาส
ตามต้นฉบับ หมายถึงตำแหน่งก่อนเข้าสู่ราศีอุจหรือมหาอุจ และมีความหมายเรื่องการยกระดับฐานะ/ความสำเร็จ โดยแจกแจงแนวโน้มไว้ดังนี้:
- อาทิตย์: อาชีพ ตำแหน่ง ความรู้ และความสำเร็จ
- จันทร์: เสน่ห์ เมตตา และการเป็นที่พึ่ง
- อังคาร: ความกล้า การบังคับบัญชา งานช่างหรือเกษตร
- พุธ: ชื่อเสียง ความสามารถ ทรัพย์ และความสัมพันธ์
- พฤหัสบดี: ความรู้ ความเชี่ยวชาญ และการสอน
- ศุกร์: ธรรมะ การค้า ยศศักดิ์ และทรัพย์
- เสาร์: ความขยัน อดออม และความมั่งคั่ง
- ราหู: เกียรติยศ ความรู้ และงานที่ต้องอาศัยความกล้า

### อุจจาภิมุข
ตามต้นฉบับเป็นตำแหน่งเลยราศีอุจไปหนึ่งราศี ให้คุณลดลงและอาจมีลักษณะ “ทุกขลาภ”:
- อาทิตย์: ความรู้ ทรัพย์ และเพื่อนฝูง
- จันทร์: ทรัพย์ ญาติบริวาร และความนิยม
- อังคาร: เกียรติ อำนาจ และความรวดเร็ว
- พุธ: ทรัพย์ บริวาร และมนุษยสัมพันธ์
- พฤหัสบดี: ผู้ใหญ่สนับสนุน ความรู้ และปัญญา
- ศุกร์: ความรู้คดีโลก/คดีธรรม ทรัพย์ และบุคลิก
- เสาร์: ทรัพย์ อำนาจ และความนับถือ
- ราหู: ชัยชนะ อำนาจ การปกครอง และทรัพย์

ต้นฉบับกล่าวถึงภพ ๑, ๔, ๕, ๗, ๙, ๑๐, ๑๑ ว่าเป็นภพที่ให้ผลดี และให้ความสำคัญกับภพกดุมภะ/ลาภะ รวมถึงเงื่อนไขการเล็งกับดาวเกษตร ข้อกำหนดเหล่านี้ต้องแยกเป็นกฎย่อยและยืนยันก่อนทำเป็นตรรกะในโปรแกรม

## 6. มหาจักรและจุลจักร

### มหาจักร
แนวความหมายตามต้นฉบับ: อิทธิพลเด่น โลดโผน พลิกแพลง แคล้วคลาด มานะ และความสามารถฝ่าอุปสรรค โดยแจกแจง:
- อาทิตย์: ลาภยศ หลักฐาน อำนาจ และความมั่งคั่ง
- จันทร์: รูปสมบัติ ทรัพย์ เกียรติ ที่ดิน และฐานะ
- อังคาร: ความกล้า อำนาจ ความเด็ดเดี่ยว และความมั่งมี
- พุธ: ทรัพย์ บริวาร เกียรติด้านวิชาการ และความเชี่ยวชาญ
- พฤหัสบดี: ความรู้ เกียรติ และความสำเร็จใหญ่
- ศุกร์: ทรัพย์ คุณธรรม และชื่อเสียง
- เสาร์: ความมั่นคง การออม และอสังหาริมทรัพย์
- ราหู: อำนาจ การปกครอง บริวาร และชัยชนะ

ต้นฉบับย้ำว่าผลเด่นขึ้นเมื่อกุมลัคนา และกล่าวถึงข้อสังเกตเฉพาะจันทร์ พุธ และราหู ให้เก็บเป็นคำอธิบายประกอบ ไม่ใช่เงื่อนไขตัดสินจนกว่าจะยืนยัน

### จุลจักร
ตามต้นฉบับเป็นตำแหน่งตรงข้ามมหาจักร ให้คุณน้อยกว่า และอาจต้องกุมลัคนาพร้อมมีดาวเกษตรเรือนนั้นสนับสนุนจึงจะเด่น ต้องยืนยันตารางตำแหน่งจริงก่อนนำไปคำนวณ

## 7. ราชาโชคและเทวีโชค

### ราชาโชค
ตามต้นฉบับเน้นวาสนา การสนับสนุน ความนิยมและการได้รับความช่วยเหลือในยามยาก:
- อาทิตย์: ความนิยมและความก้าวหน้าทางราชการ
- จันทร์: ผู้ใหญ่สนับสนุนและคู่ครองมีวาสนา
- อังคาร: ผู้มียศหรือมิตรสหายช่วยเหลือ
- พุธ: ความนิยมด้านงานเขียน ธรรมะ และวาทศิลป์
- พฤหัสบดี: นักปราชญ์ ครู อาจารย์ หรือผู้ทรงศีลเมตตา
- ศุกร์: ความนิยมจากผู้คนและความก้าวหน้าในงาน
- เสาร์: ความนิยมด้านการงานและตำแหน่ง
- ราหู: บริวารและเครือข่ายจำนวนมาก รวมถึงโอกาสด้านทรัพย์ตามคำพยากรณ์

ต้นฉบับให้ความสำคัญเป็นพิเศษเมื่อราชาโชคอยู่ในเรือนกัมมะแก่ลัคนา แต่ต้องยืนยันรายละเอียดภพและตารางดาวก่อนทำเป็นกฎ

### เทวีโชค
ตามต้นฉบับคือดาวในราศีตรงข้ามกับตำแหน่งราชาโชค และให้คุณน้อยกว่า แต่ถ้ากุมลัคนาอาจเด่นเป็นพิเศษ ข้อนี้ยังต้องยืนยันตารางหลัก ไม่ควรอนุมานค่าตำแหน่งจากข้อความเพียงอย่างเดียว

## 8. ดาวพระเคราะห์สัมพันธ์กัน

| ประเภทคู่ดาว | ความหมายตามต้นฉบับ |
|---|---|
| คู่ธาตุ | ให้คุณสูง หนุนความมั่งคั่ง ความสุข ความสมบูรณ์ และความยั่งยืน |
| คู่สมพล | เสริมกำลัง อำนาจ ความสามารถ ตำแหน่ง การคุ้มครองและป้องกัน |
| คู่มิตร | การเกื้อกูล ความเมตตา ความไว้วางใจ และการช่วยเหลือยามตกอับ |
| คู่ศัตรู | ความขัดแย้ง การทะเลาะ คดีความ อุปสรรค และความไม่ลงรอย |

คำว่า “คู่ธาตุ/คู่สมพล/คู่มิตร/คู่ศัตรู” เป็นหมวดความสัมพันธ์ระหว่างดาว ไม่ใช่มาตรฐานตำแหน่งดาวประเภทเดียวกับเกษตรหรืออุจจ์ ต้องเก็บเป็นโมดูล/ตารางแยกต่างหาก

## 9. ข้อความเฉพาะเกี่ยวกับพุธและมฤตยู

- **มฤตยู:** ต้นฉบับกล่าวว่าเมื่อสัมพันธ์กับลัคนา เช่น กุม เล็ง โยค หรือตรีโกณ อาจสื่อถึงความสนใจของเก่า การเก็บความลับ และสิ่งลึกลับ
- **พุธ:** ใช้พิจารณาคำพูด การเจรจา ธุรกิจ การประสานงาน นายหน้า การสอน การเทศน์ การเขียน และการแก้ปัญหา
- ข้อความเหล่านี้เป็นแนวตีความ ไม่ใช่กฎคำนวณมาตรฐานดาว

## 10. ข้อความเรื่องนิจและองศา — ต้องตรวจต้นฉบับก่อนใช้งาน

ข้อมูลที่ผู้ใช้ส่งมาระบุองศาจำกัด/องศาที่ “จะไม่เป็นนิจ” สำหรับดาวหลายดวง แต่ค่าที่เขียนไว้มีความไม่สอดคล้องภายใน เช่น:
- อาทิตย์ระบุองศาจำกัด 19° แต่กล่าวว่าจะไม่เป็นนิจเมื่อเกิน 10°
- จันทร์ระบุ 3° แต่กล่าวว่าจะไม่เป็นนิจเมื่อเกิน 19°
- อังคารระบุ 28° แต่กล่าวว่าจะไม่เป็นนิจเมื่อเกิน 12°
- ศุกร์ระบุ 27° แต่กล่าวว่าจะไม่เป็นนิจเมื่อเกิน 17°
- เสาร์ระบุ 21° แต่กล่าวว่าจะไม่เป็นนิจเมื่อเกิน 6°
- ราหูระบุ 1° แต่กล่าวว่าจะไม่เป็นนิจเมื่อเกิน 8°

จึงห้ามนำค่าเหล่านี้ไปเขียนเป็นสูตรอัตโนมัติหรือใช้ตัดสิน PASS/FAIL จนกว่าจะได้ตรวจข้อความต้นฉบับ ตารางดาวคู่ธาตุ และนิยามว่าองศาที่กล่าวถึงเป็นองศาในราศี องศาจำกัด หรือเกณฑ์อื่นใด

## 11. รายการงานต่อเพื่อทำเป็นระบบ

1. ยืนยันสำนัก/ตารางมาตรฐานหลักที่จะใช้
2. จัดทำตารางราศีและองศาแยกตามมาตรฐาน: เกษตร, ประเกษตร, อุจจ์, นิจ, อุจจาวิลาส, อุจจาภิมุข, มหาจักร, จุลจักร, ราชาโชค และเทวีโชค
3. ยืนยันตำแหน่งดาว ๘–๐ และดาวนอกชุดดั้งเดิมแยกจากดาว ๑–๗
4. แยกกฎคู่ธาตุ คู่สมพล คู่มิตร และคู่ศัตรูเป็นข้อมูลความสัมพันธ์ดาว
5. เพิ่ม test cases ที่มีทั้งกรณีผ่าน ไม่ผ่าน และกรณีขอบเขตองศา
6. แยกข้อความพยากรณ์ออกจากตรรกะจำแนกมาตรฐาน และให้ผู้ใช้เปิด/ปิดการแสดงคำอธิบายได้
7. ก่อนเปลี่ยนโค้ด ให้ตรวจว่าไม่มีการเปลี่ยนสูตรดาวหรือลัคนา และไม่แก้ `index2.html`
